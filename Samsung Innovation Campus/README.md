# 🐍 Módulo 1: Fundamentos de Programación y Análisis de Datos

Bienvenido a mi repositorio de fundamentos. Este bloque representa mi transición desde la lógica algorítmica más pura hasta la manipulación de datos del mundo real. No se trata solo de aprender sintaxis en Python, sino de entender cómo estructurar soluciones eficientes.

Aquí he condensado las prácticas, quizzes y proyectos de las primeras semanas de formación.

### 🧠 Habilidades y Herramientas Adquiridas

A lo largo de este módulo, desarrollé competencias agrupadas en 4 áreas clave:

**1. Lógica, Estructuras de Datos y Algoritmos**
*   **Fundamentos:** Control de flujo, bucles y resolución de problemas clásicos (algoritmos de números primos, números de Armstrong).
*   **Estructuras:** Manejo avanzado de listas, tuplas, diccionarios, listas 2D y sets. Incluye la creación y consumo de archivos JSON.
*   **Algoritmos de Ordenamiento:** Implementación desde cero de *Bubble Sort*, *Insertion Sort*, *Merge Sort* y *Quick Sort* (incluyendo versión con pivote aleatorio).
*   **Algoritmos de Búsqueda y Optimización:** Búsqueda binaria, enfoques *Greedy* (algoritmo de cambio de monedas), *Divide y Vencerás* (camino mínimo en triángulos) y *Backtracking* (resolución de cuadrados mágicos).

**2. Programación Avanzada y Paradigmas**
*   **Funciones y Recursividad:** Uso de funciones puras, llamadas recursivas (ej. detección de palíndromos) y funciones de orden superior (`map`, `filter`).
*   **Programación Orientada a Objetos (POO):** Creación de clases, métodos mágicos (`__mul__`, `__truediv__`) y encapsulamiento.
*   **Estructuras Lineales:** Implementación de Pilas (LIFO) y Colas (FIFO) mediante clases y tablas Hash.

**3. Análisis y Procesamiento de Datos**
*   **Pandas:** Creación de Series y DataFrames, filtrado avanzado, renombrado de índices y tratamiento de valores nulos.
*   **Estadística Descriptiva:** Uso de `.describe()` para obtener promedios, medianas y desviaciones estándar.
*   **Manejo del Tiempo:** Uso del módulo `datetime` para calcular diferencias de fechas y proyecciones.

**4. Visualización de Datos**
*   **Matplotlib:** Generación de gráficos de líneas, configuración de ejes y representación visual de tendencias (ej. evolución de precios en el tiempo).
*   **Análisis Exploratorio (EDA):** Procesamiento de un *dataset* real de charlas TED (extraído de Kaggle) para calcular métricas de interacción (ratio de comentarios vs. visualizaciones).

### 🏆 Retos Destacados 

*   **Algoritmos Complejos:** Resolución de problemas de optimización usando *Backtracking* y *Programación Dinámica* (ej. cálculo de coeficientes binomiales y optimización de rutas).
*   **Análisis de Datos Reales:** Descarga, limpieza y análisis del dataset de TED Talks usando Pandas para entender el impacto de las charlas.
*   **Arquitectura de Software:** Creación de un sistema CRUD (Crear, Leer, Actualizar, Eliminar) simulado mediante listas de diccionarios y menús interactivos por consola.
